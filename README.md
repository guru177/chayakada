# Kattan Chaya

A vintage Kerala tea-stall ambience mixer — rain, thunder, fire, birds, kada chatter, and a lo-fi radio — plus a chai-themed Pomodoro timer.

Inspired by [kattanchaya.in](https://www.kattanchaya.in/). Ambient layers are synthesized in the browser (Web Audio). Original songs are not streamed.

How the mixer, presets, radio, and audio graph work: **[docs/AMBIENCE.md](docs/AMBIENCE.md)**.

## Run

```bash
npm install
npm run dev
```

Open the local URL Vite prints (often http://localhost:5173 or http://localhost:5174).

- Scroll to **Ambience** or open `/#ambience`
- Click a preset or turn a knob to start sound (the browser needs that click)
- `/pomodoro` is the study timer with the same mixer
